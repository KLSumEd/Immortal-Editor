# Immortal Editor

## Overview

This software is intended to be an IDE for the ImmortalScript Language.
It comes with a built-in Editor, Interpreter, Compiler and Debugger.

## Editor

The Editor provides an interface to write ImmortalScript files with useful tools like static syntax highlighting, and automatic code generation.

## Interpreter

The Interpreter is built-in to the editor to allow for easy debugging. It can also be called on from the command-line or using the terminal view to run a REPL to help test small code snippets.

## Compiler

The Compiler allows ImmortalScript files to be 'transpiled' into an ImmortalModel object file that can then be executed using an ImmortalEngine distribution.
